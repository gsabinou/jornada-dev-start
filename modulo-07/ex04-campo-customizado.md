# Exercício 4 - Campo customizado 
## A. "Defina tipo, tamanho e título do campo no Configurador.

Para isso é simples, basta entrar no SIGACFG, Base de dados > Dicionário > Base de dados, aí lá dentro procurar pelo dicionário de dados e procurar a tabela SA1. Encontrando-a, iremos a selecionar e clicar em editar. Lá, iremos selecionar campos e vamos clicar em incluir. O nome do campo será A1_XAPELID, seu tamanho será de no máximo 30 e seu tipo será caracter, além do seu título ser "Apelido do cliente". Após isso é só atualizar a base de dados clicando em atualizar.

Após isso, podemos abrir o SIGAFAT ou SIGAMDI sem problema algum pelo smartclient, que quando nós formos realizar um novo cadastro, o campo estará lá para ser preenchido.
